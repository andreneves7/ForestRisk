# Page 2 — Previsão ML: Build Guide

## Data source
Athena table: `forest_risk.mock_predictions` (CSV, via ForestRiskAthena ODBC DSN, eu-west-1, Import mode)
Generated by `scripts/generate_mock_predictions.py`. 50 rows, model_version = "v0.1-mock".

## Visuals

### Treemap — Risco Previsto por Região
- Group: `regiao`
- Values: `AVERAGE of predicted_risk_score`
- Conditional formatting: green → yellow → red (0–100)
- Title: "Risco Previsto por Região"

### KPI Cards (right column)
- **Zonas Alto Risco**: DAX measure (see below)
- **Confiança Média**: `AVERAGE of confidence`, format as "0.0%"  
  Note: if confidence is stored as 60-95 (not 0.60-0.95), format as "0.0" and add "%" suffix manually in card title
- **Versão Modelo**: `FIRST of model_version` (aggregation: First), shown as text card

### Bar Chart — Top 10 Regiões
- Y-axis: `regiao`
- X-axis: `AVERAGE of predicted_risk_score`
- Sort: descending
- Top N filter: 10
- Title: "Top 10 Regiões — Risco Previsto"

### Detail Table
- Columns: `grid_id`, `regiao`, `predicted_risk_score`, `confidence`, `model_version`
- Default sort: `predicted_risk_score` descending
- Format numeric columns to 1 decimal place
- Title: "Detalhe por Zona"

### Disclaimer Text Box (bottom, full width)
- Text: `"⚠️ Dados simulados — modelo ML em desenvolvimento. Não usar para decisões operacionais."`
- Font: 11px, italic, colour #666666
- Background fill: #FFFACD (light yellow)

## DAX Measures

```dax
Zonas Alto Risco =
CALCULATE(
    COUNTROWS(mock_predictions),
    mock_predictions[predicted_risk_score] > 70
)
```

## Data type note
Power BI may import `predicted_risk_score` and `confidence` as Text (because OpenCSVSerde returns all values as strings). In Power Query, change these columns to Decimal Number type before loading.

## Steps to Build
1. Get Data → ODBC → ForestRiskAthena → forest_risk → mock_predictions → Transform Data
2. In Power Query: change `predicted_risk_score` and `confidence` column types to Decimal Number → Close & Apply
3. Add page tab, rename to "Previsão ML"
4. Add Treemap (regiao / predicted_risk_score / conditional formatting)
5. Add 3 KPI cards (Zonas Alto Risco DAX, Confiança Média, Versão Modelo)
6. Add bar chart Top 10 regions
7. Add detail Table visual
8. Add disclaimer text box at bottom
9. Verify Zonas Alto Risco KPI shows ~15-20 (based on seeded data)
10. Save as ForestRisk.pbix
